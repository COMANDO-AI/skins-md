# CONTRIBUTING.md

SKINS.MD is built around one idea: a single markdown file should make an AI interface feel different.

Think Winamp skins, but for assistants.

## Contributing a skin

1. Copy `SKIN.template.md`.
2. Fill Sections 1–6. They are required.
3. Add v2 atmosphere/layout/component fields if the skin needs a stronger world.
4. Keep the skin readable as plain text.
5. Avoid infringing IP. Use archetypes and moods rather than copyrighted characters.
6. Test import in the app.

## What makes a good skin

- It changes micro-copy, not just colors.
- It has a clear emotional register.
- It remains readable after the novelty wears off.
- It has a shareable screenshot.
- It uses optional visual presets to create atmosphere without making the chat unusable.

## Non-goals for MVP contributions

No accounts, server storage, analytics, payments, crypto, or arbitrary JavaScript execution inside skins.
